Репозиторий содержит код Terraform для развертывания базовой инфраструктуры в Yandex Cloud. Инфраструктура включает:

- **VPC сеть** с подсетью  
- **Вычислительный ресурс** (VM)  
- **Serverless YDB база данных**  
- **Объектное хранилище (с бакетом)**  
- **Сервисный аккаунт** с ролью editor и статическим ключом для доступа к объектному хранилищу 

## Настройка Terraform
1. Экспорт переменных окружения для аутентификации в Yandex Cloud:
```bash
export TF_VAR_token=$(yc iam create-token)
export TF_VAR_folder_id=$(yc config get folder-id)
export TF_VAR_cloud_id=$(yc config get cloud-id)
```
2. Инициализация Terraform
```bash
terraform init
```
3. Планирование развертывания
```bash
terraform plan
```
4. Применение конфигурации
```bash
terraform apply
```
5. Удаление ресурсов
```bash
terraform destroy
```

## Описание
Инфраструктура состоит из пяти модулей:

- network – создаёт виртуальную сеть и подсеть для всех ресурсов.
- compute – разворачивает виртуальную машину (VM) для приложения.
- database – разворачивает базу данных.
- iam – создаёт сервисный аккаунт с ролями и статическим ключом для доступа к объектному хранилищу.
- storage – создаёт объектный бакет для хранения данных приложения.
